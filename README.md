# ☕ カフェ経営アカデミー

カフェを3年間（12四半期）経営しながら、MBA入門レベルの経営知識を体で覚えるブラウザゲームです。

## 学べること

| 期 | テーマ | ゲーム内の出来事 |
|---|---|---|
| 1 | 損益計算書（P/L） | 開業 |
| 2 | 変動費・固定費と損益分岐点 | 夏の閑散期 |
| 3 | 価格弾力性 | コーヒー豆の価格高騰 |
| 4 | 貸借対照表（B/S） | |
| 5 | ポーターの競争戦略 | 大手チェーンが出店 |
| 6 | キャッシュフローと黒字倒産 | |
| 7 | 在庫と機会損失 | 雑誌掲載で客が急増 |
| 8 | ブランドと広告投資 | |
| 9 | ROEとデュポン分析 | 最低賃金の引き上げ |
| 10 | 設備投資（回収期間・NPV） | |
| 11 | KPIと外部環境 | 大型オフィスビル完成 |
| 12 | 総まとめ | |

## 遊び方

1. 毎期、価格・原材料のグレード・仕入数・スタッフ数・広告費（＋改装投資と借入）を決める
2. 右側の「経営ダッシュボード」で損益分岐点と処理能力をリアルタイムに確認
3. 決算後、P/L・B/S・C/Fとメンターの講評を読む
4. その期のレッスンを読み、確認クイズに答える
5. 3年後のROE（累計純利益 ÷ 資本金）で S〜E の評価

## ローカルで動かす

ビルド不要の静的サイトです。

```bash
python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます。

## 構成

- `index.html` — 画面
- `js/engine.js` — 需要・P/L・B/S・C/F の計算（UI非依存）
- `js/lessons.js` — レッスンとクイズ、用語集
- `js/app.js` — UI
- `css/style.css` — スタイル（ライト／ダーク対応）

進行状況はブラウザの localStorage に保存されます。数値は学習用に簡略化したモデルです。
